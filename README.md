# 🧮 CalcPro — Scientific Calculator

**CalcPro** is a professional, responsive, and feature-rich scientific calculator web application built using HTML, CSS, and JavaScript. It combines Casio-inspired scientific functions with a modern user interface to provide a convenient mathematical calculation experience.

## 🌟 Features

### 1. Basic Calculator
- Addition, Subtraction, Multiplication, and Division
- Percentage calculations
- Decimal numbers
- Parentheses support
- Clear and Delete functions

### 2. Scientific Calculator
- Trigonometric functions (sin, cos, tan)
- Inverse trigonometric functions
- Logarithm (log and ln)
- Square root and cube root
- Power calculations (x², x³, xʸ)
- Factorial (x!)
- Absolute value
- Mathematical constants (π and e)
- Reciprocal (1/x)
- DEG and RAD modes

### 3. Calculation History
- View previous calculations
- Reuse previous expressions
- Clear calculation history

### 4. Graph Plotting
- Plot mathematical functions
- Interactive function input
- Adjustable X-axis range
- Coordinate grid

### 5. Unit Converter
- Length
- Mass and Weight
- Temperature
- Area
- Volume
- Speed
- Time
- Digital Storage

### 6. Programmer Calculator
- Binary (BIN)
- Octal (OCT)
- Decimal (DEC)
- Hexadecimal (HEX)

### 7. Additional Features
- Dark and Light themes
- Keyboard support
- Memory functions (MC, MR, M+, M−)
- Previous answer (Ans)
- Copy calculation results
- Responsive design for mobile, tablet, and desktop
- Modern user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML Canvas API
- Browser Clipboard API

## 🚀 How to Use

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Select the calculator mode you need.
5. Start calculating!

## 💻 Installation

Clone the repository:

```bash
git clone https://github.com/smsrabon/CalcPro-Scientific-Calculator.git
```

Open the downloaded project folder and run `index.html` in your browser.

No additional software, backend, or external library is required.
